Hipóteses: a forma ideal de Bernoulli pressupõe escoamento permanente, incompressível, sem dissipação viscosa relevante e aplicação ao longo de uma linha de corrente. Para bombas, turbinas e perdas de carga, use a forma estendida. Para Mach elevado, choques ou forte compressibilidade, use relações de escoamento compressível.

Bernoulli ideal entre dois pontos

P₁/(ρg) + α₁V₁²/(2g) + z₁ = P₂/(ρg) + α₂V₂²/(2g) + z₂

α é o fator de correção de energia cinética. Para perfil aproximadamente uniforme, α≈1.

Bernoulli estendido

P₁/(ρg)+V₁²/(2g)+z₁+Hₚ−Hₜ−hL = P₂/(ρg)+V₂²/(2g)+z₂

Pressão de estagnação — forma incompressível

q = ½ρV² · P₀ = P + q

Adequado quando efeitos de compressibilidade são pequenos. Para escoamento compressível, a relação de pressão total deve considerar Mach e γ.

Venturi — vazão por diferença de pressão

Q = Cd·A₂·√[2(P₁−P₂)/(ρ·(1−(A₂/A₁)²))]

Forma simplificada para mesma cota e fluido incompressível. Em medidores reais, Cd deve ser compatível com a geometria e faixa de Reynolds.
